Jot 0.1.0，轻一点的新开始。

Jotlet 更名为 Jot。原有七页便签、设置和备份继续使用，无需迁移数据；保留 0.3.1 的全选修复。从旧版迁移请下载新版安装包。

安装只需几步

先安装，再从菜单栏打开。

  1. 打开下载的 DMG

    找到 Jot-0.1.0-preview.dmg，双击打开安装窗口。

  2. 拖入 Applications

    将 Jot 拖入 Applications（应用程序）。如果已安装旧版，请先正常退出，等待保存完成后再替换。从 Jotlet 手动升级时，请将原来的 Jotlet.app 重命名为 Jot.app 后再替换，避免同时保留两个入口。原有便签会自动沿用。

  3. 打开 Jot

    在访达的“应用程序”中打开 Jot。启动后，点击屏幕顶部的菜单栏图标即可记事；安装完成后可推出 DMG。

首次打开

如果 macOS 提示无法验证。

当提示无法验证开发者，或 Apple 无法检查是否包含恶意软件时，仅在确认安装包来自本官网或项目官方 GitHub 版本页、且未遭篡改后，按以下步骤操作。

  1. 先尝试从“应用程序”打开一次 Jot，再打开“系统设置”。
  2. 进入“隐私与安全性”，向下找到与 Jot 对应的拦截提示，点击“仍要打开”。
  3. 按系统提示确认身份，并在再次出现的提示中点击“打开”。

无需关闭 Gatekeeper、修改全局安全设置或运行终端解锁命令。不同 macOS 版本的提示文字可能略有不同。查看 Apple 官方操作说明 ↗

还有一点疑问？

没有看到“仍要打开”？+

先从“应用程序”尝试打开 Jot，再查看“隐私与安全性”。受公司或学校管理的 Mac 可能不允许此操作，请联系设备管理员。如果仍无法安装，可在项目 GitHub Issues 中反馈 macOS 版本和完整提示文字。

提示“已损坏”或“将损坏电脑”怎么办？+

这些提示不能一概当作未公证提示处理。请停止打开，从本页重新下载并核对 SHA-256；如果仍有提示，请向项目反馈。不要通过关闭系统防护或删除隔离属性强行运行。

安装后没有看到普通应用窗口？+

Jot 是菜单栏应用。启动后请在屏幕顶部找到 Jot 图标，点击它打开便签小窗。

更新前需要做什么？+

建议先导出完整备份。手动替换应用前请正常退出旧版，避免中断保存。支持应用内更新的版本也可以从菜单中检查更新。
